## How to Add Claude Code in Terminal

### Prerequisites
- A Claude **Pro, Max, or Teams** account
- Node.js installed on your system
- macOS, Linux, or Windows

### Installation

Install Claude Code globally via npm:

```bash
npm install -g @anthropic-ai/claude-code
```

### Authentication

Run the following command in your terminal:

```bash
claude
```

This opens your browser to log in with your Anthropic account. Once authorized, return to your terminal and you're ready to go.

### Basic Usage

Navigate to any project directory and use Claude Code:

```bash
# Start an interactive session
claude

# Run a one-shot task
claude "explain this codebase"

# Get help
claude --help
```

For full documentation, visit: https://docs.anthropic.com/en/docs/claude-code
